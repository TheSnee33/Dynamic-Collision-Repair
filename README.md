# Dynamic Collision Repair — Website

> Family-owned auto body & collision repair shop in Provo, UT since 1979.

## 🏢 About

Dynamic Collision Repair has been serving Utah County since 1979. Founded by Robin Roberts, the shop offers quality collision repair, auto body work, paint & refinishing, frame alignment, rim repair, and vehicle inspections — all backed by a lifetime warranty.
